# Demo image credits

The photos below are used only for the seeded demo listings. They live in
`src/main/resources/static/uploads/` and are tracked in Git so that a
fresh clone renders the listings without anyone having to upload files first.
On startup the app copies them into the `stored_images` table, so a production
database serves them the same way it serves user uploads.

All images come from [Wikimedia Commons](https://commons.wikimedia.org/) and are
used under the licence shown. If you replace a photo, update this table.
